### Project Description
**Real Cat Translator 🐱** — Types your English text into cat-speak and plays it back using real, verified cat recordings (meows, purrs, hisses, snores) pulled live from Wikimedia Commons, one sound per word. A single-file HTML/JS "useless project" with no dependencies, built for TinkerHub Useless Projects.

### The Problem (that doesn't exist)
Cats have been living in our homes for thousands of years and we still can't understand a single word they say — yet somehow we've mapped the human genome and sent robots to Mars. So I built the fix nobody asked for: a translator that turns your everyday sentences into confident-sounding meows, backed by real recorded cats, so you can finally respond to your pet with something other than a guilty stare and an early dinner. It won't cure any diseases, but it will let you lose an argument to your cat in their own language.

### The Solution (that nobody asked for)
Type any English sentence, hit a button, and watch it get chopped word-by-word into pure cat gibberish — "meow," "mrrrow," "nyaa," take your pick — then hear it read back to you in an authoritative sequence of *actual* cat recordings, not some robot doing a bad impression. No AI models, no APIs to pay for, no cats were harmed or even consulted — just genuine feline audio, fetched live and played back with total conviction, whether you typed "hello" or "please stop knocking things off the table."

## Technical Details
### Technologies/Components Used
For Software:
- **Languages used:** HTML, CSS, JavaScript
- **Frameworks used:** None — vanilla JS, single file
- **Libraries used:** None (uses the browser's native Web Audio / `Audio` API)
- **Tools used:** Wikimedia Commons API (for resolving live URLs to real cat sound recordings), any modern web browser

For Hardware:
- N/A — this is a pure software project

### Implementation
For Software:

**Installation**
No installation needed — it's a single self-contained `.html` file with no dependencies to install.

**Run**
```
# Just open the file directly in any modern browser:
open cat_translator.html      # macOS
start cat_translator.html     # Windows
```
Or double-click the file / drag it into a browser tab. An internet connection is required so it can fetch the real cat clips from Wikimedia Commons.
